# 🧪 Packet Tracer Labs

Build each lab yourself in **Cisco Packet Tracer** (free from Cisco Networking Academy, netacad.com).
After each lab, **save your `.pkt` file in this folder** and tick it off in [PROGRESS.md](../PROGRESS.md).

| # | Lab | Domain |
|---|---|---|
| 01 | [Basic device setup + SSH](01-basic-setup-ssh.md) | Security / IP Services |
| 02 | [VLANs & trunking](02-vlans-trunking.md) | Network Access |
| 03 | [Inter-VLAN routing (router-on-a-stick)](03-inter-vlan-routing.md) | Network Access / IP Connectivity |
| 04 | [STP root bridge & PortFast](04-stp.md) | Network Access |
| 05 | [EtherChannel (LACP)](05-etherchannel.md) | Network Access |

| 09 | [ACLs](09-acls.md) | Security |
| 10 | [Port Security + DHCP Snooping](10-port-security.md) | Security |

**How to do each lab**
1. Build the topology.
2. Configure it **without looking** at the solution first.
3. Verify it with the `show` commands listed.
4. Do the **🔨 Break it** challenge, then fix it. This is how you get good at troubleshooting!
