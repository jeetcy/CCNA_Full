# ⚙️ Config Templates

Starting configs you can copy and paste. Replace everything in `<ANGLE_BRACKETS>` with your own values.

| File | Use it for |
|---|---|
| [router-base.txt](router-base.txt) | A new router: hostname, security, SSH, NTP, logging |
| [switch-access-base.txt](switch-access-base.txt) | A new access switch: VLANs, access ports, trunk, security |

⚠️ These are lab templates. **Never** upload real company configs or real passwords to GitHub!
